# Responsive Menu Block Closer



This is a very simple module that performs a single task:



It will close the responsive/mobile Primary Menu when you click or tap *outside*
of the menu itself.  This is the expected behavior from most users, yet, it
was not working in various themes.



## Installation

* Install this module using the official Backdrop CMS instructions at
  https://backdropcms.org/guide/modules



## Usage

Once the module is enabled, make sure your Primary Navigation menu is set to display
as a **block** somewhere on the page.
